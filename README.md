# 📝 Mini Blog Portfolio

Este é um projeto de blog simplificado desenvolvido para demonstrar competências Full Stack. A aplicação conta com uma interface pública para leitura de conteúdos e uma área administrativa restrita para gerenciamento de postagens.

## 🚀 Tecnologias

- **Backend:** Java 21, Spring Boot 3, Spring Security, JWT, JPA/Hibernate.
- **Frontend:** Angular 17+, Tailwind CSS.
- **Banco de Dados:** H2 (Dev) / PostgreSQL (Prod).

## 🛠️ Funcionalidades

- **Área Pública:**
    - Listagem de posts por ordem cronológica.
    - Leitura completa do post com suporte a formatação.
    - Design responsivo para dispositivos móveis.

- **Área Administrativa:**
    - Autenticação segura via JWT.
    - CRUD completo de posts (Criar, Ler, Atualizar e Deletar).
    - Feedback visual de ações (Toasts de sucesso/erro).
